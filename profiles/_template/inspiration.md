# Inspiration

Creators this person actually enjoys reading, stored as **extracted behaviours
only**. The pasted source text is discarded at the end of setup, so another
writer's sentence can never reach a draft.

No `last_reviewed`. A creator you liked in February is still a creator you like.

Loaded at draft time **only** when `voice.md` declares that no samples exist.

## What counts as an extraction

Usable: "opens mid-story with no setup," "one-line paragraphs throughout,"
"closes on a question he then answers himself," "never uses a number without
naming where it came from."

Not usable: "engaging," "authentic," "punchy," "great storyteller." A profile
made of adjectives is the failure mode.
